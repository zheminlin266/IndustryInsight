# 公司名称（模板）

复制本文件并以公司名称命名。一家公司参与多个环节时，在同一档案中分别记录，并链接相关环节。

- 更新日期：待填写。
- 公司全称、简称及证券代码（如适用）：待核实。
- 研究覆盖的业务与期间：待确认。
- 所属环节：待添加环节档案链接。

## 公司画像

| 维度 | 待研究的问题 |
| --- | --- |
| 业务与资产 | 有哪些相关业务、矿山或项目？运营、持有与权益关系是什么？ |
| 供给变化 | 产能、产量及项目进展如何变化？区分公告计划与实际产出。 |
| 同行竞争 | 哪些企业在相同产品和市场中形成竞争？差异是什么？ |
| 客户与需求 | 向哪些客户供货？需求与采购安排如何变化？ |
| 成本与交易 | 成本口径、定价方式、合同与付款条件是什么？ |
| 约束与历史 | 存在哪些经营约束？历史上发生过哪些重要变化？ |
