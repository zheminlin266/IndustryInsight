## 环节画像

| 维度 | 待研究的问题 |
| --- | --- |
| 功能与边界 | 提供什么价值？投入、产出和产品范围是什么？ |
| 供给结构 | 主要供应者是谁？产能、产量、库存及新增或退出供给如何变化？ |
| 竞争格局 | 主要参与者、集中度、进入壁垒与替代关系如何？ |
| 下游需求 | 由谁采购、用于什么用途？需求量、客户结构和采购行为如何变化？ |
| 交易机制 | 价格、合同、成本传导和付款条件如何安排？ |
| 瓶颈与依赖 | 哪些约束影响有效供给？谁控制受限要素？什么条件能够缓解？ |
| 历史演变 | 发生过哪些关键变化？对供需与竞争结构产生了什么影响？ |
