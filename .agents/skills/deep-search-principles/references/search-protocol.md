# 搜索协议

在需要规划搜索、补证、重试或判断饱和度时读取。研究模式与核心约束见 [技能入口](../SKILL.md)。

## 来源地图与优先级

按商业问题选择来源，默认优先：

1. 公司原始披露、监管文件、官方统计、交易所公告、财报、电话会、投资者演示、分部附注、技术文档。
2. 客户与渠道实证：采购文件、客户案例、产品评论、实施伙伴、经销商与迁移讨论。核对证据是否独立，厂商选出的案例不能替代独立客户证据。
3. 竞争对手与供应商：披露、定价、产品比较、胜负单、产能、交付周期、依赖、认证与联合公告。
4. 方法透明的行业协会、数据库、调查、主流与垂直媒体。
5. 咨询摘要、博客和普通社媒仅作辅助与线索，不单独作关键论据。

可补充政府许可登记、海关、招投标、法院/执法、破产、诉讼、召回、竞争法、数据保护、知识产权与产品安全记录，以及标准、认证、专利和公共合同。

互联网与技术问题可查官方文档、产品更新与状态页、GitHub/GitLab、官方 issue tracker、客户实施、竞争替代；包下载量、Docker Hub、仓库活跃度、贡献者和 issue 关闭周期均需说明代理指标的局限。App Store、Google Play、G2、Capterra、Trustpilot、开发者论坛、Discord/Slack 社区及招聘中的技术栈、支持岗位、区域扩张可提供相关运营线索。流量、应用排名、库存、进出口、门店数等只在与问题相关时使用。

官方公司/机构 X 账号的原始发布可作一手披露，但须核对账号和上下文。微信公众号按方法透明的行业媒体评估，先核验作者、出处与数据口径；可通过搜狗微信搜索检索。Reddit 与普通社媒主要用于口碑、线索与反方证据。三类平台均按问题相关性检索，不强制每题全查。

学术论文仅用于技术可行性、消费者行为、经济机制、政策影响或长期基准；通过 Google Scholar、arXiv、SSRN 等追到原论文，不因形式完整而堆叠论文。

## 时间窗口与工具

- 用户指定的期间优先；开始前记录 timeRange。
- 快速变化的 AI/政策/加密领域通常看最近 6 个月，技术课题最近 1 年，行业趋势最近 2 年，学术综述最近 5 年，历史研究可不限。当前价格、监管、指引等仍须核验当前适用日期。
- 优先最近 2 年内数据与研究；超过 5 年的来源标注年份并解释有效性。窗口外材料用于历史比较和背景，历史对比本身不受此限制。
- 优先默认网络搜索工具；关键页面读取全文。已有来源池满足相关性与时效时先复用。
- 商业研究先查监管/交易所、IR、官方统计、采购、定价/产品、客户/渠道、竞争对手和协会。咨询报告追踪定义、方法与被引原始数据。
- 技术搜索以官方文档和原始仓库为证据；社区用于发现问题。按需用 site:reddit.com、site:x.com / site:twitter.com 或搜狗微信搜索（weixin.sogou.com），核验原始发布。

## 按证据缺口选择查询族

下列十类是工具箱，不是逐项必跑清单：

1. 直接问题 + 实体 + 地域 + 期间。
2. 同义词、缩写、旧名称、产品、母子公司和当地语言。
3. 官方/监管/公司 site:、filetype:pdf、统计、采购与数据集。
4. 收入、销量、价格、份额、产能、用户、留存、流失、利润率、成本、利用率等定量词。
5. 客户、供应商、伙伴、分销商、实施商与渠道。
6. 替代、比较、迁移、胜负单、定价、评论与份额。
7. 批评、失败、延期、取消、诉讼、召回、故障、风险与做空观点。
8. 招聘、评论、流量、开发者活动、库存、进出口等相关运营信号。
9. 向后追原始引用，向前找更新、纠错与反驳。
10. 与问题相关的 Reddit、X、微信公众号定向搜索。

重要商业因果判断尽量形成公司/监管 + 客户/渠道 + 竞争对手或独立来源的证据三角；缺失时明确限制。核对一个公告中的已披露事实无需强制寻找三类材料。

## 重试与停止

首轮不足时按缺口选择原关键词定向、同义词/上位概念、换来源与语言、引文追踪/参与者反搜/适度放宽时间四类方法；不因来源数少而机械跑满四轮。放宽时间后标记旧材料的适用范围。

以下情形需要补证：关键主张缺少原文；只有同一新闻稿的转述；数字缺期间或口径；相关客户/竞争/反方维度缺失；覆盖矩阵有影响结论的 gap。来源种类和数量只能提示覆盖风险，不能替代这些判断。

停止标准按研究深度调整：

- 快速核查：原文直接支持所问事实，必要口径与日期清楚。没有争议的公告事实无需机械追加反方查询或两组无增量查询。
- 单章/完整研究：关键数字和结论可信，有一手来源或记录了获取失败；相关反方、失败、风险证据已搜索；冲突已解决或保留；追加不同查询已不再改变关键事实、参与者或判断。连续两组无重要增量可作为饱和信号，不是所有任务的固定门槛。
- 关键缺口仍在时继续有针对性的合理补证。若资料不可得、付费阻挡、访问受限或追加搜索不再有实质收益，记录已尝试方法、原因、未解问题及缩小范围/接受降级的选择；不得称该问题已完成或编造来源补位。

完整报告约 5 来源/主题、3 类型/主题、20 来源/报告仅作覆盖参考。多篇材料引用同一原文只算一条独立证据链；有更多链接不代表证据更充分。
